# Fishing OS v0.5 – Tackle-Modell Klarstellung

Status: finalisiert nach Gesamtcheck

Diese Datei hat Vorrang vor widersprüchlichen Formulierungen in älteren Tackle-Entwürfen.

## Klare Trennung

### Köder
Ein Köder ist das eigentliche Lockmittel, z. B.:
- Creature Bait
- Shad
- Worm
- Jerkbait
- Chatterbait
- Spinnerbait
- Crankbait

Ein Ködertyp ist **kein Rig**.

### Rig / Montage
Eine Montage beschreibt, wie Komponenten kombiniert werden, z. B.:
- Texas Rig
- Carolina Rig
- Dropshot
- Ned Rig
- Jika Rig
- Free Rig
- Cheburashka
- Weedless Offset

### Komponenten
Eigenständige Bestandteile, z. B.:
- Haken
- Bullet Weight / Gewicht
- Jigkopf
- Snap
- Wirbel
- Vorfach
- Hauptschnur
- Trailer, sofern als eigenes Objekt gepflegt

### Setup
Ein Setup verbindet die komplette verwendete Gerätekette:
- Rute
- Rolle
- Hauptschnur
- Vorfach
- Verbindung
- Rig / Montage
- Köder
- Haken / Beschwerung / Terminal Tackle

## Historische Ereignisse

Bei einem Fang oder anderen Ereignis wird eine Momentaufnahme der tatsächlich verwendeten Kombination gespeichert, wenn der Nutzer sie angibt. Spätere Änderungen am Katalog dürfen den historischen Zustand nicht verändern.

## Hardbaits mit festen Haken

Fest verbaute Eigenschaften eines Köders, z. B. Anzahl und Typ der serienmäßigen Drillinge eines Jerkbaits, dürfen direkt als Ködermerkmal gespeichert werden. Austauschbare bzw. bewusst konfigurierte Komponenten können zusätzlich separat referenziert werden.

## Statistik

Die Trennung ermöglicht unabhängige Auswertungen nach:
- Ködertyp
- konkretem Köder
- Rig / Montage
- Haken / Hakengröße
- Beschwerung
- komplettem Setup

Doppelte Speicherung derselben fachlichen Information an mehreren Stellen wird vermieden.

## Produktregel

**Köder ist Köder. Rig ist Montage. Setup ist die komplette Kombination.**
